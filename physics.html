How to Play

🎮 Levels

Complete each level by triggering the chain reaction. Start the simulation and watch the physics unfold!

🔧 Design Mode

Build your own Rube Goldberg machines from scratch. Select elements from the left panel, place them on the canvas, and test your creation.

  • Left Click: Place selected element or select existing element
  • Delete Mode: Toggle the red Delete Mode button, then tap any element to remove it
  • Right Click: Remove element (desktop only)
  • Drag: Move existing elements (when not simulating)
  • Properties: Select an element to edit rotation, size, and more

⚙ Controls

Use Start/Reset to control the simulation. Slow Mo lets you watch in detail. Switch themes anytime for a different visual style!
